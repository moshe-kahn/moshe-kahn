# Moshe Kahn

UCLA B.S. Computer Science (2019). I design and build practical
software: data-driven tools shaped around the state a person is
actually in, not just the category of their problem.

Independent software developer, creator of
[Kahntra Productions](https://kahntra.com/tech).

## Current work

[**Momo Movies**](https://momomovies.app) is a curator-led movie
discovery app that matches what you want to watch right now with
what's available on your streaming services. The
[public showcase](https://github.com/moshe-kahn/momo-movies-showcase)
covers the product, how it works, and the design challenges behind
it.
